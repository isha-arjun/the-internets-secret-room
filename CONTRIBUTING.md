**CONTRIBUTING**

Thank you for your interest in contributing!

THE INTERNET'S SECRET ROOM is a browser-based mystery puzzle game. Contributions that improve its puzzles, story, accessibility, reliability, or presentation are welcome.
Ways to contribute
- Report a bug or confusing puzzle.
- Suggest a new case, clue, or story improvement.
- Improve accessibility and mobile usability.
- Fix a technical issue.
- Improve documentation.
- Suggest visual or sound improvements.
Before you start
For substantial changes, open an issue first to discuss the idea. This helps avoid duplicated work and keeps the game's mystery, difficulty progression, and atmosphere consistent.

Please do not submit copied artwork, music, writing, or code unless you have permission to use it.
Making a change
1. Fork the repository.
2. Create a branch for your change.
3. Make a focused improvement.
4. Test it in a modern browser.
5. Submit a pull request explaining what changed and why.
Testing checklist
Before submitting, check that:
- The game opens without obvious errors.
- Existing cases still accept their intended answers.
- Case unlocking works in the correct order.
- Hints display correctly.
- Progress saving and resetting work.
- The layout remains usable on mobile and desktop.
- Keyboard navigation still works.
- New puzzles have clear, verifiable solutions.
Puzzle submissions
A puzzle proposal should include:
- A title and difficulty level.
- The exact clue presented to the player.
- The intended answer.
- A clear explanation of the solution.
- Optional hints in increasing levels of helpfulness.
Avoid puzzles with multiple plausible answers unless the game explicitly accepts them.
Pull requests
Keep changes focused and describe:
- The problem being solved.
- What you changed.
- How you tested it.
- Any limitations or follow-up work.
Please be respectful and constructive when discussing suggestions.

Thank you for helping improve the archive!
