**Reporting a vulnerability**

If you discover a security issue in THE INTERNET'S SECRET ROOM, please report it privately to the repository owner through GitHub rather than posting sensitive exploit details publicly.

Include:
- A brief description of the issue.
- The steps needed to reproduce it.
- Its potential impact.
- Any suggested fix, if known.
Please do not access, modify, or disclose other people's data while investigating a possible issue.
Project scope
This is a client-side browser game. It does not require a backend, account system, or paid API. Browser storage is used to save local game progress.

Security reports are welcome, although fixes and response times are not guaranteed.
