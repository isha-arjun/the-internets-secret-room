
# ◈ THE INTERNET'S SECRET ROOM

> Some files were never meant to be found.

**A mysterious, browser-based puzzle game where you investigate a lost research archive, solve 10 increasingly difficult cases, decode hidden messages, and uncover the truth behind PROJECT ECHO.**

## 🕵️ The Story

Seventeen years after PROJECT ECHO went dark, a message arrives at an abandoned research terminal.

No sender. No route.

Just one instruction: *If you're reading this, start with the signal.*

Explore the archive, examine corrupted records, solve puzzles, and follow the evidence. Every case brings you closer to the truth—but the final file may change how you understand the investigation.

## ✨ Features

- 🔍 **10 progressive cases** — from simple patterns to a final meta-puzzle.
- 🧩 **Multiple puzzle types** — logic, sequences, ciphers, timestamps, and deduction.
- 🗝️ **Progressive hints** — get help when you need it.
- 📁 **Unlockable archive** — solve cases to access new files.
- 🌌 **Immersive interface** — dark sci-fi visuals, animated stars, scanlines, and terminal effects.
- 💾 **Local progress saving** — resume your investigation in the same browser.
- 🔊 **Optional sound effects** — enable audio whenever you want.
- 📱 **Responsive design** — play on desktop or mobile.
- 🔒 **No accounts or paid APIs** — the game runs entirely in your browser.

## 🚀 Play the Game

**Live demo:** Add your GitHub Pages URL here after publishing.

Alternatively, you can run it locally:

1. Download or clone this repository.
2. Open `index.html` in a modern web browser.
3. Click **ESTABLISH CONNECTION**.
4. Investigate the archive and solve the cases.

## 🔐 Privacy

The game does not require an account or send puzzle progress to a server. Progress is saved locally in your browser using Local Storage.

Clearing browser storage or resetting the investigation can erase saved progress.
